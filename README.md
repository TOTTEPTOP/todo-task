# Менеджер задач (ToDo List)

Веб-приложение для управления списком задач. Можно добавлять задачи, отмечать выполненные и удалять ненужные.

## Стек
- Python 3, Flask
- SQLite
- HTML

## Как запустить локально
1. pip install flask
2. python app.py
3. Открыть http://127.0.0.1:5000
